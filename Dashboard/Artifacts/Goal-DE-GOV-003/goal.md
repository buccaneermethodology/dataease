# DE-GOV-003：本地 SGE 优化持续收益观察

目标：根据后续 DataEase 真实任务的耗时、返工、验收质量和测量成本，持续判断 DE-GOV-002 本地优化是否适合保留或调整。每新增 5 个已结束且完成一次观察的合格任务，发布一轮评估；失败、中止及数据缺失任务照样入册，不挑选成功样本。每轮结论可以是证据不足，不以证明优化有效作为完成条件。

范围：本项目后续使用本地 SGE 的非平凡任务。本地 Skill 本体保持评估时版本；规则改变后另起 cohort。只写本项目观察材料、必要的 AGENTS 采集入口与 Dashboard 记录，以及本聊天持续检查配置。其他仓库、全局 Skill、产品代码和数据库不在写范围。

用户要求见 [原文](raw-user-intent.txt)。协议和字段先固定；所有统计标注分母、来源和缺失量。单一历史安装任务仅作诊断案例；模型、任务类型、复杂度或入口不同的墙钟差不作为因果收益。

本轮子目标是建立方案与持续采集机制（见 setup-goal.md）；长期观察状态为 doing。每轮报告完成仅结束该轮，不关闭本长期 Goal。持续至用户停止或明确修改范围；不会自动升级、回滚或发布 Skill。
