# 单任务评估报告模板

## 结论与声明边界

给出暂支持保留 / 需要调查调整 / 收益不明显 / 证据不足之一；明确本任务事实、累计量化门槛和质量红线。只描述观察性结果。

## 本任务与原始分母

本次 task_id、revision、cohort、终态；成功/失败/中止及缺失字段。注明累计登记、已结束、进行中、排除及 coverage_unknown。指向冻结输入清单。

## 耗时、返工与质量

列本任务与累计指标的有效 n、缺失 n、中位/范围；主要时间点缺失保留 null。必要审阅与可避免返工分开；原始任务墙钟、整体治理墙钟和收尾墙钟均展示可用值。

## 对照与采集成本

列配对规则、配对 IDs、差异和未匹配原因；累计不足5个同口径配对时不报量化收益百分比。展示内联和 observer 成本及净收益参考；注明并发并集和无法测量项。

## 决策与后续

逐项对照协议阈值；说明此前单任务报告的连续支持情况。建议及支持证据。报告不自动授权修改 Skill，不用报告通过代替原任务验收。
