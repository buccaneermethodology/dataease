# 第 N 轮：五任务观察报告

## 结论与声明边界

给出暂支持保留 / 需要调查调整 / 收益不明显 / 证据不足之一；质量红线单独说明。只描述观察性结果。

## 批次与原始分母

批次5个ID、revision与cohort；成功/失败/中止/缺失数；累计登记、已结束、进行中、排除及coverage_unknown。指向冻结输入清单。

## 耗时、返工与质量

各指标本批/累计的有效n、缺失n、中位/范围；必要审阅与可避免返工分开；原始任务墙钟、整体治理墙钟和收尾墙钟均展示可用值。

## 对照与采集成本

配对规则/IDs/差异/未匹配原因；配对不足不报收益百分比。展示内联和observer成本及净收益参考；注明并发并集和无法测量项。

## 决策与后续

逐项对照协议阈值；上一批是否重复出现；建议及支持证据。报告不自动授权修改 Skill，不用报告通过代替原任务验收。
