# 用户补充原文

**目前没有已确认具备真实多用户权限能力的隔离测试环境，也没有可提供的受限测试账号。**

现有环境是本机 `127.0.0.1:7070`，后端 `8100`、专用库 `dataeasev3`。此前使用的是 standalone 模式下的 `admin`；这不能证明只读用户限制、权限撤销等真实鉴权行为，也不能用来验收这些要求。

S02 需要准备：

- 加载真实权限实现的隔离实例。
- 至少两个持久测试账号：可编辑用户、只读用户；管理员用于调整和撤销授权。
- 固定测试组织及资源，凭据存入本机安全配置或密码管理器，通过配置位置获取。
- 保留账号供后续开发复用；权限撤销用例结束后恢复约定的基准权限。登录会话仍正常过期，不设置永久 Token。

\*\*目前不能把现有 admin 直接当作这套权限账号。\*\*需要先确认可用的权限模块及部署方式，再建立上述长期开发环境；在此之前，S02 可以推进设计，但这些权限验收必须保留为未验证。
