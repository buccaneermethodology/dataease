# F01 验证实施入口

本轮只建立规格，未执行产品测试；全部16项仍NOT_RUN。当前package.json没有统一test脚本；不能把构建/ts:check当功能验收。

## 分层验证

1. 共享核心：纯逻辑可控时钟、UTF-8字节边界、50/51叶子、非法结构、完整深拷贝、旧载荷保全；受审后冻结Cases与RED identity。
2. 适配层：图表/查询各自真实模型，字段与数据集ID，完整承载、引用和循环；确认前无写入，取消/失败零查询，成功只按既有snapshot链刷新。
3. 真实入口：同浏览器两个标签、不同仪表盘；U_editor/U_view/U_none及权限撤销；拦截并记录请求与实际配置/命中ID，禁止以mock权限证明真实拒绝。
4. 持久化：P0旧树、成功粘贴预览{2,3,5}、保存成功重开、保存失败另一会话仍P0、正常取消不变。既有服务未获本任务隔离确认前不启动或写库，不占用S01窗口/测试对象。
5. 回归：原过滤新增/删除/清空、原组件复制/改类型、快照撤销/重做、普通图/表/透视和相关query；适用移动/嵌入入口明确是否受共享代码影响，不能默认通过。

## 执行与证据

代码Builder进入后选择最小测试入口，真实命令/环境/fixture/预期/实际/日志/快照写TestEvidence，逐条回填CoverageMatrix新版本。前端定向eslint（不加fix）、ts:check用于静态辅助；不执行带build:flush安装副作用的构建作为轻量检查。后端如改契约，核对Surefire实际运行报告。

测试证据至少包含源与目标序列化前后、预览命中ID、刷新次数/网络、保存版本与身份；日志不含token或真实业务数据。动态规则采用实际支持表达式，固定时钟/时区，不能发明函数。
