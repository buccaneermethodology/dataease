## FX-WEIGHT：防止展示结果二次平均

底层110条记录：A001..A010每条销售100、利润20、利润率0.2；B001..B100每条销售100、利润30、利润率0.3。透视可能只展示A/B两产品。目标右侧AVG利润率为 `(10×0.2+100×0.3)/110=32/110=0.29090909…`，两位百分比29.09%，不能25%。SUM利润3200/SUM销售11000也为29.09%。只过滤A时20%，只过滤B时30%。这个样本可揭露对两个产品展示行平均的错误，不能使用A/B各一条来代替。

## FX-EXPR：具体函数向量

使用FX-AGG三条记录且均授权。期望原始数值：SUM销售600，AVG销售200，COUNT销售3，MAX销售300，MIN销售100，`(SUM(销售)-SUM(利润))/SUM(销售)`=2/3，`SUM(利润)*2+10`=410，`ABS(SUM(利润)-SUM(销售))`=400，`ROUND(SUM(利润)/SUM(销售),4)`=0.3333；`IF(SUM(销售)>0,1,0)`=1；`CASE WHEN SUM(销售)=0 THEN 0 ELSE SUM(利润)/SUM(销售) END`=1/3；`COALESCE(NULL,7)`=7（如解析器要求字段型输入，用最终NULL聚合表达式替代并固定后续oracle）。具体字段引用token需映射现有语法，不将中文展示名当必然可执行语法。

反例：未知函数XXX、删去闭括号、SUM文本类型、无权限利润字段、外数据集字段、解析器定义的非法聚合嵌套、带任意SQL执行企图。期望禁止保存/执行，结构化错误尽可能定位但不泄漏SQL/连接/堆栈。不臆造通用合法嵌套清单；需S01解析规范固定。

## FX-NULL：局部异常

组东销售300利润80→26.67%；组南销售0利润50→空值；组北销售200利润NULL且最终表达式NULL→空值。两异常不阻断东，不能自动0。南的显式CASE WHEN SUM销售=0 THEN 0 ELSE比值 END→0；显式COALESCE最终NULL,7→7。聚合如何忽略NULL、全NULL的SUM等必须沿Provider，若Provider中最终并非NULL则不能套该NULL结果前提；空值显示符号同样保持现有机制。

字段被删的Invalid Configuration须明确不可用并保留配置，不能与合法零除的空值混同。其他指标继续。重命名同ID兼容继续，ID替换不能自动按名字匹配。

## FX-HIER：多层组独立底层计算

## FX-EXPORT-AGG：三格式汇总

华东底层销售300利润80，华南销售500利润75，合计800/155；自定义右侧总计利润率=155/800=0.19375，百分比两位19.38%。XLSX实际值0.19375且百分比格式，CSV文本19.38%，图片显示19.38%；不得用两区域百分比简单平均20.833…%。异步执行前数据改变应按执行时底层重算，不要求文件与提交瞬间页面严格快照。
