# KB 门槛可读验收场景

本批用户要求全部中间件归SP，故可读场景保存在本目录，不另写产品tests/bdd。长期工具位于kb/tools；固定输入与程序见planning/cases、tools/test_kb_v2.py。

- 给定源码真实片段与正确身份/摘要，当校验候选时，则结构与引用通过，但不产生运行通过结论。
- 给定执行Dashboard或全景Dashboard作正式证据，当准入时，则拒绝来源。
- 给定错误仓库或revision，当准入时，则拒绝，不因文件内容同名而通过。
- 给定失效摘要，当校验时，则拒绝，并可独立用impact定位受影响事实、能力和关系。
- 给定unknown类别、重复ID、悬空关系或越界输出路径，当校验时，则分别拒绝。
- 给定相同JSON，当重复投影时，则输出字节一致；测试资产明确未运行。

实际13场景结果见kb-tool-tests-v2.json；本表不替代真实执行或独立语义复核。
