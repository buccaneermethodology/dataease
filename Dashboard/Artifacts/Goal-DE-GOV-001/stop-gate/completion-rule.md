# DE-GOV-001 Goal completion rule

仅当原始用户请求对应的 AC-01..AC-06 全部由当前文件状态和最终独立验证支持、没有未批准的范围变更或待决人类决策、最终 Dashboard 与收尾材料已完成 readback、Stop Gate 的 11 类最终证据均绑定且所有 Goal 工作单元终态时，才允许 terminal closeout。

声明限制：原 Dashboard README 没有 Git HEAD 字节基线，故 AC-03 只要求既有记录字段级语义保留；execution-admission 的历史上下文摘要当前不可复验，必须在独立审阅与 closeout 中明示，不得声称该历史摘要当前有效。当前范围不要求 Dashboard registry、DataEase runtime、数据库或外部发布验证。
