  - Product
    - Info
      - Product Description
        - DataEase README 将产品描述为开源 BI 工具，帮助用户分析数据、洞察业务趋势并改进业务；这是公开产品描述，不代表本候选验证了实际效果。
      - Version / Build Declaration
        - 根 POM 声明 DataEase 版本 3.2.0、Java 21 与 Spring Boot 3.5.15；这是构建配置声明，不是运行环境事实。
      - Repository Architecture
        - 根 Maven 聚合器只列 SDK；core 单独聚合前后端；SDK 聚合 common、api 与 extensions，承载共享代码、业务接口和扩展契约。
      - License Description
        - 仓库 LICENSE 将 DataEase V3 授权描述为带附加条款的 GPLv3 修改版；具体授权信息以 LICENSE 原文为准。
    - Naming Conventions
      - Data Source
        - 数据源是代码中的连接与接入配置对象；CoreDatasource 保存类型、加密配置、状态及同步相关元数据。
      - Dataset
        - 数据集由数据集分组、表和字段等对象组成，可记录关系/联合 SQL、跨源属性及字段元数据。
    - Scope
      - Publicly Described Product Scope
        - README 对外列出多类 OLTP/OLAP、数据仓库/数据湖、Excel/CSV 与 API 数据源，并描述拖拽制作图表和分享。该项记录公开产品范围表述。
      - Extension Contract Boundary
        - 当前收录的开放仓库证据包括 SDK 的 XpackResource 嵌入管理契约，以及主前端 PluginComponent 插件加载桥。
      - Requested Source Boundary
        - 本首版 KYM 按用户要求以项目 KB 与仓库代码为来源。
    - Exclusions
    - Business Rules
      - Data Source and Dataset
        - Create and Update Data Sources
          - 保存请求带有正 ID 时进入更新；新建路径解码配置、执行前置检查并生成 ID。连接状态失败会记录 Error 状态，随后仍进入 innerSave；因此连接检查不等于保存必然被拒绝。
        - Provider Selection
          - 数据源查询按类型选择 Provider：ES 使用专用 Provider，内置类型走 Calcite，其他类型走插件缓存并要求有效 License；无法取得插件实例时抛出异常。
        - Save Datasets
          - 非重命名的数据集保存若缺少 allFields 会被拒绝；保存过程构建联合 SQL/关系信息，并为数据集节点保存表与字段。
        - Dataset Preview Permissions
          - 编辑预览入口固定为前 100 行且不检查权限；已保存数据集预览启用权限检查。权限检查开启时会按列规则过滤字段，并在无列权限时拒绝；存在用户身份时加载行权限。
      - Chart and Data Queries
        - Chart Data Request
          - 普通图表取数请求依次执行视图解码、计算、视图编码和数据编码；模板数据来源走独立扩展数据路径。
        - Chart Permissions
          - 普通图表计算先要求数据集存在并通过 READ 权限检查，再获取列权限、脱敏规则和行权限，并从图表各轴移除无权字段。
        - Cross Source Queries
          - 跨源查询由 Calcite 使用 PreparedStatement 绑定参数；单源路径委派 JDBC。失败会转为取数错误，并在 finally 中尝试关闭结果集与语句。
      - Sharing and Visitors
        - Share Token Issue
          - 分享 Token 签发前检查分享是否启用、iframe许可、创建者授权、密码/Ticket与有效期；条件不满足时返回挑战信息而不签发资源 Token。
        - Share Token Scope
          - 链接 JWT 绑定分享、创建者、资源与组织；令牌寿命最多八小时且不超过分享有效期，签名还绑定当时的 UUID、密码、Ticket要求和访客权限设置。
        - Link Request Validation
          - 链接请求只允许 GET/POST，并要求路径在显式通用路径或受 DeLinkPermit 保护的接口范围内；资源查询必须匹配链接资源，静态资源须在分享画布配置中且文件名不能含目录穿越结构。
        - Visitor Permissions
          - 访客明细、数据导出和图片导出分别使用位值 1、2、4；许可有效时，访客权限取分享配置与创建者权限的交集，缺少所需位时拒绝操作。
      - Export
        - Export Authorization
          - 图表明细导出首先检查访客导出权限；请求按身份和配置走同步文件写入或导出任务。数据集异步导出会过滤列、应用行权限和导出筛选，无列权限时失败。
        - Export Download Tickets
          - 下载 URI 绑定当前用户的导出任务，下载记录有效期五分钟；下载端校验 Ticket、任务、所有者、签名和有效期，通过后删除下载记录。
